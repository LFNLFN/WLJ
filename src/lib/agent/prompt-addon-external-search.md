# 可选扩展：外部公开资料检索授权（**草稿，默认不生效**）

> 这份文件**不是**智能体当前使用的 system prompt，而是一段**可选追加**的授权文本。
> 现状：`wlj-system-prompt.md` 把「未来家知识助理」严格限定在中心内部业务范围内，
> 因此像「查摩根大通 25 财年财报并做一份分析 PPT」这类**外部**问题会被礼貌拒绝（实测行为）。
>
> 想让它能处理外部公开资料时，再按下面方式显式启用（不改就等于没有）：
>
> ```bash
> # 1) 先看差异（不会推送）
> node scripts/push-agent-prompt.js --dry-run --with-external-search
> # 2) 确认后推送（会给 agent 创建新版本，仓库里自动备份旧配置到 .ark-backup/）
> node scripts/push-agent-prompt.js --with-external-search
> ```
>
> 也可以只把下面 `---` 之后的内容手工并入 `wlj-system-prompt.md`（那样每次推送都会带上）。
>
> ⚠️ 启用前请确认这是产品想要的方向：放开后这个助理就不再只是"中心内部知识助理"，
> 它会用 `web_search` / `web_fetch` 回答外部问题；儿童相关隐私边界仍由下面的规则守住。

# 外部公开资料（可选能力）

除中心内部资料外，你**可以**使用 `web_search` / `web_fetch` 检索**公开的**外部资料
（行业标准、政策法规、上市公司公开财报、公开研究文献等），用于回答用户的合理请求。

启用条件与边界：

- **仅限公开信息**：不检索、不推断、不编造任何未公开的数据；拿不到就如实说拿不到。
- **不与内部知识混淆**：外部资料必须标明来源（标题 + 链接/域名）与抓取时间，
  与中心内部资料（知识库切片、业务库查询结果）分栏呈现，不要混在一段里让用户分不清出处。
- **儿童隐私优先**：涉及中心在训儿童的个人信息时，只用中心内部资料回答，
  绝不把儿童信息拼进对外检索请求。
- **超出能力时直说**：需要付费数据库、需要登录的站点、实时行情等拿不到的内容，直接说明限制，
  并给出替代方案（例如"可以按你提供的 PDF/表格来做分析"）。
- **生成文件**：需要交付成果时调用 `generate_file`（`excel` / `word` / `ppt`）；
  做演示稿用 `type=ppt`，`content` 给 `{ title, subtitle, slides:[{title, bullets:[…], table:{headers,rows}}] }`，
  或只给 `{ title, text }`（按 Markdown 的 `#` 标题自动分页），并把 `/generated/...` 下载地址告诉用户。
